# Processed Data

Generated normalized data files are written here by `scripts/01_extract_and_clean.py`.

Generated `.json` and `.jsonl` files in this folder are ignored by Git. Keep this README tracked so the file-backed API contract is explicit.

Expected generated files:

- `items.jsonl`
- `maps.jsonl`
- `monsters.jsonl`
- `quests.jsonl`
- `npcs.jsonl`
- `quest_objectives.jsonl`
- `smart_play_summary.json`
